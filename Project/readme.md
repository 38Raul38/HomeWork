Пользователь может выбирать категорию (спорт, технологии, бизнес и т.д.), и сайт загрузит актуальные новости по выбранной теме. Каждая новость содержит заголовок, краткое описание, дату публикации и ссылку на оригинальный источник

 Также реализована кнопка "Load More" для подгрузки дополнительных новостей и `тёмная тема` с переключателем. Интерфейс адаптирован под мобильные устройства
