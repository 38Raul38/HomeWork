# 🌤 Проект: Интерактивное веб-приложение прогноза погоды с авторизацией

Это веб-приложение включает:

---

## 🔐 Авторизация

- Форма входа и регистрации с валидацией через **RegEx**
- Проверка e-mail, пароля и других полей по шаблону
- Поддержка логина и регистрации с сохранением пользователей в `users.json`
- Хэширование паролей через `bcrypt`

---

## 🗺 Карта Google Maps

- После входа пользователь переходит на страницу с интерактивной картой
- Можно кликнуть по любой точке и выбрать геолокацию

---

## 🌦 Прогноз погоды

- После выбора точки происходит переход на другую страницу
- Используется API **OpenWeatherMap** для загрузки:
  - Температуры
  - Ощущаемой температуры
  - Влажности
  - Описания погоды
  - Скорости ветра
  - Ближайших городов в радиусе

---

## 📄 Пагинация

- Отображение информации разбито по страницам (по 5 городов за раз)

---

## 🚀 Технологии

- HTML, CSS, JavaScript (Vanilla)
- Node.js + Express
- Google Maps API
- OpenWeatherMap API
